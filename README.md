# UGRT Docs

Based on Quartz V4. Contents is in `/content`

## Developing

- You will need `npm`
- Install dependencies using: `npm i`
- Run locally with `npx quartz build --serve`
- Upload changes with `npx quartz sync`
- Update Quartz with `npx quartz plugin install --latest`
